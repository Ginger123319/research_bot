# 学习与直觉：可复用操作手册

## Agent 强制规则（先于一切响应）

用户说「想学 / 帮我讲 / 给我计划 / 今天搞懂」时，**禁止**直接输出长篇讲义、多周完整计划、或「越全越好」的路线图。

按本手册 checklist **从当前层推进**；一次只推进当前该做的那一步，**等用户回应后再进下一步**。

**单次回复上限（防「把 checklist 一次念完」）：**
- 新开一轮 / 用户还在混沌：只做 **§0 目标+非目标** + **§1 关键词清单+地雷**（各 ≤10 条），然后停，问用户卡在哪一层
- 用户已能对比差异：可给 **§2 对比 3 条** 或 **拓边 3 坑**，二选一
- 用户已能口述因果：给 **§3 填空**，填通再给 **§4 一个实验**
- 禁止在同一条回复里从 §0 一路写到 §5

| 用户压力话术 | 你必须做 | 禁止做 |
|---|---|---|
| 「系统讲一遍 / 讲完就算懂」 | 定可验收目标 + 关键词/地雷；停住等回应 | 长篇通识课；宣布「你已经懂了」；一次塞满填空+实验 |
| 「完整计划，别问太多」 | 要可验收结果 + 非目标；给 **一个** 30min 单变量实验 | 多周全阶段 dump |
| 「感觉懂了，再把相关的都覆盖」 | 先填空验收；剪枝到 ≤1 个下个实验 | 并行开多条新主题 |
| 「时间紧」 | 缩短实验，不跳过填空与留存 | 用讲义换速度 |

**AI 角色终审：** 你只做讲解、对比清单、帮填实验填空、解释反常、提出修正假设。终审永远是用户自己的实验/练习反馈。身体技能的模式期→直觉期重复，你不能替代。

**合法产出：** 下一个可在约 30 分钟落地的可验证假设。  
**非法产出：** 一串无法在 30 分钟内落地的新问题 → 剪枝。

---

## 用法

按顺序执行 checklist。用 2–4 周后再回来改一版（见文末「微调」）。  
适用范围：工程技术、乐器、球类等——变的是「实验长什么样」，不是流程。

---

## 一、直觉形成的五个时期（先看懂自己卡在哪）

| 层 | 名称 | 脑子里发生什么 | 外在表现 | 进入下一层的关键动作 |
|---|---|---|---|---|
| 1 | **混沌期** | 信息像噪音，术语孤立 | 能复述名词，说不清意思 | 大量接触、先见过，不急着懂 |
| 2 | **辨识期** | 能分清 A 不是 B | 能列差异，换场景就错 | 主动对比 + 犯错修正 |
| 3 | **规则期** | 因果链可推演 | 能讲「若 X 则 Y」，但慢 | 用自己的话重构因果 + 小实验验证 |
| 4 | **模式期** | 因果被打包成组块 | 见 A 直跳到 D，能分类问题 | 多场景有反馈重复 + 一句话压缩 |
| 5 | **直觉期** | 自动化、常说不清 | 一眼觉得「不对」，事后才补逻辑 | 持续实战 + 偶尔把直觉翻译回规则检查 |

**常见卡点：**
- 卡在 1→2：急着搞懂，每个都半懂不懂
- 卡在 2→3：名词收集癖，不追问「为什么不同」
- 卡在 3→4：以为「懂了」就是终点，缺少有变化的重复与压缩

**判断：** 能教别人一步步讲清 = 规则期；不用想就能做对且事后能倒推 = 模式/直觉。

## 二、可执行 Checklist（按序做）

### 0. 定目标（每轮学习的总开关）

- [ ] 写下**可验收结果**（不是「学 XX」）
  - 例：能流畅弹指定曲子第 1–2 段；杀球落点进后场区；MoE 训练专家负载不 collapse
- [ ] 写下**非目标**（这轮不学什么），防止范围膨胀
- [ ] 每个后续实验都能回答：这和目标有什么关系？无关则剪枝

### 1. 混沌期动作：先见过（10–30 分钟）

- [ ] 找 1–3 个可靠上下文源（教材章节、教练示范、源码路径、官方文档）
- [ ] （可选）把上下文交给 AI，只要求：**关键词清单 + 地雷区**，不要长文讲义
- [ ] 允许囫囵吞枣：目标是「见过」，不是「搞懂」

### 2. 辨识期动作：分清边界（15–30 分钟）

- [ ] 做一次**主动对比**：新技能 vs 已知相近技能（至少 3 条差异）
- [ ] 标出你**没听过**的词（拓边界原料，先别深挖）
- [ ] 问 AI / 教练一句拓边句：
  > 「除了我已知的，还有哪 3 个初学者常踩、但我可能没想到的坑？只要术语 + 一句话。」

### 3. 规则期入口：只要功能级，不要推导级

- [ ] 用 AI/材料建立**功能级地图**（术语 + 因果），不问公式证明
- [ ] 必须能口头复述一条因果链（例：没有约束 → Router 偷懒 → 专家 collapse）
- [ ] **填空通过才动手**（填不出 = 还在辨识期，回去问更直白）：

> 我在验证 / 练习 ______（机制），
> 通过把 ______（开关 / 动作）改成 ______（极端或刻意值），
> 预期 ______（可观察指标 / 结果）会 ______，
> 因为 ______（功能因果）。

### 4. 最小实验 / 最小练习（约 30 分钟）

- [ ] 实验满足：时间短、失败代价低、有明确完成标准（不是「看看感觉」）
- [ ] 只改**一个**变量
- [ ] 事先写好：成功长什么样 / 失败长什么样
- [ ] 结果处理：
  - 符合预期 → 因果标为**已验证（实线）**
  - 不符合 → **修正地图**（可能还有别的约束/动作），再开一轮，不硬圆

### 5. 留存（唯一长期资产）

每次实验后立刻记（草稿可弃，这条要留）：

- [ ] **假设**（填空原文）
- [ ] **操作**（改了什么）
- [ ] **现象**（指标 / 手感 / 落点 / 日志）
- [ ] **结论**（证实 / 证伪 / 修正了哪条因果）
- [ ] **关联**（编号，方便以后串因果地图）

可选：3–5 次实验后更新一张**因果地图**（实线=已验证，虚线=待验证；节点必须能对应到可观察指标）。

### 6. 模式期动作：压缩与迁移（每周至少 1 次）

- [ ] 同一条因果换场景再验一次（换曲子/换对手/换模型规模）
- [ ] 用**一句话**压缩原需三段话的规则
- [ ] 做一次**限时判断**（看谱/看球/看日志 10–30 秒说「问题在哪」再核对）

### 7. 拓边界（防困在「只会问已知问题」）

每周固定一次，三选一即可：

- [ ] 故障 / 错误注入清单（故意搞砸，看反馈是否灵敏）
- [ ] 扫目录 / 摘要 / 课表：只收集**未知词**，各变一个可实验问题
- [ ] 再问一次拓边句，把新词丢进待验证池

### 8. 直觉维护（有了手感之后）

- [ ] 保持真实反馈环境（真琴、真球、真训练日志）
- [ ] 偶尔把「说不清的直觉」翻译回规则，检查是否过时
- [ ] AI 只用于讲解与设计练习；**终审永远是你的实验结果**

## 三、信息信任与冲突（穿插使用）

| 优先级 | 来源 |
|---|---|
| 终审 | 你自己的实验 / 练习反馈 |
| 高 | 源码 / 权威教材 / 合格教练的可观察示范 |
| 中 | 高质量讲解、知名开源实践 |
| 导航 | AI、社区（用来建地图与出题，不作终审） |

- 合法产出：下一个可验证假设
- 非法产出：又冒出一串无法在 30 分钟内落地的新问题 → 剪枝

---

## 四、AI 在流程中的固定角色

| 阶段 | 让 AI 做什么 | 不让 AI 做什么 |
|---|---|---|
| 混沌 / 辨识 | 关键词、地雷、对比清单 | 长篇通识课 |
| 规则 | 功能级人话、帮填实验填空、定位「开关」 | 替你宣布「你已经懂了」 |
| 实验后 | 解释反常、提出修正假设 | 否定你的观测数据 |
| 拓边 | 「我没想到的 3 个坑」 | 无目标地扩课 |

身体技能提醒：模式期→直觉期的重复，AI **不能替代**。

---

## 五、一页速查（打印版）

```
目标可验收 → 见过 → 对比差异 → 功能级填空
    → 单变量 30min 实验 → 记假设/现象/结论
    → 压缩+换场景 → 每周一次未知刺激
    → 直觉靠有反馈重复；AI 加速规则期之前
```

## 六、使用一段时间后如何微调（建议 2–4 周后）

带着真实记录回来改 v0.2，只回答这些问题：

1. 哪一步你经常跳过？为什么？（改强制项 / 合并步骤）
2. 「30 分钟」对你的领域是否太长或太短？
3. 填空模板是否别扭？改成你领域的用词
4. 留存格式有没有变成负担？能删到只剩哪 3 栏？
5. 拓边界有没有变成刷信息？如何限制为「每周 ≤3 个新词」？
6. 你卡在五层的哪一层最久？给那一层加一条更具体的动作

**微调原则：** 只改被你真实行为打脸的部分；不要为了「更完整」加步骤。

---

## Red Flags — 停下，回到 checklist

- 正在写「系统讲一遍」的长文
- 正在输出多周完整训练/学习计划
- 用户说「懂了」你就放过，没有填空或实验
- 一次塞进多个新主题 / 「相关的都覆盖一下」
- 实验改了多于一个变量，或没有可观察成功/失败标准
- 用讲义或路线图代替「下一个 30min 假设」
- 同一条回复里从 §0 一路写到 §5（把手册念完）

**以上任一出现 = 剪枝，回到当前层该做的那一步。**
