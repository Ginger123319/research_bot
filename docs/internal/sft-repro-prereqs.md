## 需要确认的问题

**数据**

- 文件字段名是什么（messages / conversations / ...）
- max_length 是多少，超长截断还是丢弃
- 有没有 loss_scale 加权（think token / system token），配置在哪

**模型**

- 生产用的是哪个模型（122B / 235B），架构确认是 MoE + MLA 吗
- 本地复现建议用哪个小基座（1B–7B）
- 需不需要手动 `register_model`，怎么验证生效
- MLA 权重映射有没有特殊处理，代码在哪

**训练配置**

- 122B / 235B 的典型并行度：TP / PP / EP / DP 各是多少
- 这些并行参数和 batch size 怎么算的（举个例子）

**监控与稳定性**

- 目前使用的主要有哪些监控指标
- 怎么判断所有 rank 都正常进了训练循环
- loss NaN / spike 有没有历史案例和处理方法
- 断点续训有没有不稳定的场景，有没有 workaround
