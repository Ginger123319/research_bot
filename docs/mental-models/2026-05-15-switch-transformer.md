### Top-1 Routing（稀疏路由）

**是什么**（1-2 句）：稀疏路由指的是输入token在后续计算过程中，并不需要跟每个专家都进行计算，每次只激活部分参数进行计算；而TOP-1指的是每个token只路由到一个expert进行计算

**关键工程事实**（2-4 条，**必须包含适用前提 / 边界**）：

- 稀疏路由中，每个专家和token的关系是一对多的，也就是一个专家可能被多个token选中

- 每个专家有容量的概念，也就是一个专家最多能够容纳多少个token，当专家的容量满的时候，再命中的token会被丢弃，不参与专家计算

- 因此专家之间负载均衡成为一个急需解决的问题，这个从工程角度来说非常重要，不然就会出现专家训练程度不一致，能力差异大

### Load Balancing Auxiliary Loss（负载均衡辅助损失）

**是什么**（1-2 句，写出损失公式：α · N · Σ f_i · P_i 是什么含义）：其中f_i表示expert_i存放的token总数，P_i代表每个token路由到expert_i上的概率之和；可以看出来当一个expert上的token越多，那么f_i和P_i就会越大，仅当每个expert上的token数呈现均匀分布时，两者的乘积达到最小值1/N（这里的N是层专家数）；那么这里乘以N的左右也很明显，就是使得当到达最小值时，loss是一个常量α ，工程经验一般取10的负二次方，这样既不影响整体的训练损失，又能够较快的做到专家之间的load balance！

## 对照原文后的差异补充

> 第一次默写完之后填这一节。**不要重写全篇，只列"我漏了什么 / 写错了什么"**——漏的点和错的点就是你的真实学习成果，下次复习重点看这里。

### Top-1 Routing 的差异

- token到expert是一对一，而expert到token才是一对多，即一个专家上可以容纳多个token，但一个token只能放在一个专家上

- 

### Capacity Factor 的差异

- 训练时需要冗余（防 drop 影响梯度信号），一般取 >1.0

- 推理对 drop 容忍度高，可以更小，从而降低一些推理成本
- 如果 capacity factor = 1.25，单卡激活值比 1.0时多25%，只是expert中待计算的token数目增加了，只影响激活值显存

### Load Balancing Auxiliary Loss 的差异

- f_i做了argmax操作，因此是不可微的，反向传播时，这个位置不计算梯度，仅仅考虑P_i来参与反向传播

### 训练稳定性技巧的差异

- Selective Precision / Init Scale / Dropout：分别表示训练时使用不同的精度，在router层训练时使用fp32的高精度，而其他层使用bf16之类的低精度
