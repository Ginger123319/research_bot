## 结论摘要（先读这 5 条）

1. **核心机制**：瘦子长肉 = **持续热量盈余**（约 +500-700 kcal/日）+ **足量蛋白质**（1.6-2.0 g/kg 体重）+ **抗阻 / 高强度训练**刺激合成，三者缺一不可，仅靠"多吃"容易长成"瘦胖子"。
2. **本菜单热量目标**：日均 **3200 kcal**（蛋白 130g / 碳水 420g / 脂肪 90g），按 3 正餐 + 2-3 加餐分布，单餐不超过 1000 kcal 以避免肠胃负担。
3. **执行优先级**：**碳水管够 + 优质蛋白 + 加餐别断**比"吃哪种神奇食物"更重要。坚果、全脂牛奶、花生酱、牛油果是最划算的"热量密度放大器"。
4. **羽毛球日特别处理**：训练前 1 小时补香蕉 + 牛奶；训练后 30 分钟内补乳清蛋白 / 牛奶 + 米饭或面包，关键窗口不要错过。
5. **最常被瘦子忽视的两点**：① **吃得不够**比例最高（自以为吃多其实只有 2200 kcal）→ 用第八章卡路里自检表对账；② **肠胃容量不够** → 先用 2 周加餐过渡，逐步把胃撑大。

## 一、瘦子长肉的底层原理（先理解再执行）

### 1.1 为什么瘦子怎么吃都不胖？

| 常见原因 | 解决方向 |
|----------|----------|
| 基础代谢相对高（瘦人 NEAT 高） | 增加摄入，减少无意义活动 |
| 食量小、容易饱、肠胃吸收差 | 多餐少量、流食/糊状食物提高密度 |
| 三餐之间断粮 | 强制加餐，每 2-3 小时进食一次 |
| 蛋白质摄入不足，无法合成肌肉 | 每 kg 体重 1.6-2.0g 蛋白 |
| 不训练，多余热量变内脏脂肪 | 抗阻 + 球类运动配合 |

### 1.2 营养目标（按 65 kg 男性 + 中等活动量举例）

| 项目 | 数值 | 主要来源 |
|------|------|----------|
| 总热量 | 3200 kcal | 米面 + 油脂 + 肉蛋奶 |
| 蛋白质 | 130 g（1.7 kcal/g 的 17%）| 鸡蛋、鸡腿、牛肉、鱼、奶、豆制品 |
| 碳水 | 420 g（53%）| 米饭、面、燕麦、土豆、面包、水果 |
| 脂肪 | 90 g（25%）| 坚果、牛油果、橄榄油、全脂奶、肥瘦肉 |

> 体重 ≠ 65 kg 时按比例缩放：每多/少 5 kg，热量约 ± 200 kcal。

## 二、菜单设计原则（为什么这么排）

1. **单餐 ≤ 1000 kcal**：瘦子胃容量小，过量一餐反而吃不下也吸收差。
2. **每 2.5-3 小时进食一次**：3 正餐 + 2-3 加餐，全天不出现「饿到饱」的循环。
3. **每餐都有蛋白源**：每餐 25-40g 蛋白，比一次集中 100g 利用率高。
4. **训练日多 +300 kcal**：来自训练前/后加餐，不影响正餐节奏。
5. **工作日省时，周末备餐**：周日晚批量做 4-5 份主菜；午餐尽量带饭或可预测的外卖。
6. **高热量密度优先**：相同体积下选脂肪多的版本（全脂奶、五花肉、牛油果），避免「吃饱了但没吃够」。

### 9.8 单灶台增重的 5 个隐藏技巧

1. **油是最便宜的热量来源**：同一道菜「1 勺油 → 2 勺油」+100 kcal、几乎不影响口感与饱腹感。最划算的热量加法。
2. **晚餐多一锅汤**：紫菜蛋花汤 / 番茄蛋汤 / 玉米排骨汤，10 分钟搞定，多塞 200-300 kcal 进胃，且帮消化。
3. **速冻饺子是好朋友**：自己包 / 买好的速冻 200g + 一颗蛋 + 紫菜汤 = 30 分钟一餐 ≈ 700 kcal。
4. **保温饭盒值得投入**：300-500 元的保温饭盒能让中午带饭的体验接近热乎饭，否则一周后大概率放弃带饭——这是 9.1 表格能否落地的关键单点。
5. **周三复盘冰箱**：每周三晚检查冰箱剩余食材，**当晚把快过期的优先做掉**（番茄+蛋+面 = 经典救急组合），剩 2 天的食材再决定要不要补货。

### 9.9 食材选购指南：米与油（增重场景专版）

> **追加日期**：2026-05-07
> **触发问题**：家里没米没油了，怎么买最划算？
> **核心原则**：增重场景下，「米选软糯能多吃 + 油选耐高温香味重」比「健康减脂"显著优先级更高，因为**吃得下才能长肉**。

#### 9.9.1 米：选东北粳米（圆粒）

增重场景的最优解，**不要全用糙米/糙杂粮米**——饱腹感太强，瘦子半碗就饱，反而吃不够热量。

| 类型 | 特点 | 适合增重？ | 推荐度 |
|------|------|-----------|--------|
| **东北粳米**（圆粒，软糯）| 黏性好、口感软、吃得下大份量 | ✅ 强烈推荐 | ⭐⭐⭐⭐⭐ |
| 五常大米 / 稻花香 | 粳米中的高端，米饭油亮香甜 | ✅ 体验升级 | ⭐⭐⭐⭐⭐ |
| 籼米（南方长粒，泰国香米）| 颗粒分明、偏硬、不黏 | ⚠️ 一般，吃量受限 | ⭐⭐⭐ |
| 糙米 / 全麦米 | 高纤维、高饱腹感、低 GI | ❌ **不要全用**（瘦子吃不动）| ⭐ |
| 紫米 / 黑米 | 营养好但口感偏硬 | 混入 10-20% 即可 | ⭐⭐⭐（混搭用）|
| 减肥米 / 魔芋米 / 高纤维米 | 主打低热量饱腹 | ❌ 完全相反 | 别买 |

**预算分档：**

| 预算 | 推荐 | 价格区间 | 适合 |
|------|------|---------|------|
| 经济款 | 东北圆粒米 5kg 真空袋 | 25-35 元/5kg | 学生党、入门 |
| **性价比首选** | **五常大米 5kg（认产地标）** | **50-70 元/5kg** | 长期吃 |
| 体验升级 | 原产地稻花香 / 蟹田米 | 100+ 元/5kg | 偶尔奖励 |

**购买注意点：**
- 买 **5kg 真空包装**最划算，1 人吃约 3-4 周
- 看 **生产日期 < 3 个月**（新米口感更好）
- 五常 / 盘锦 / 响水 是北方好米带；包装上需有 **GB/T 19266（五常）** 这种地理标志才是真的
- 紫米 / 黑米 / 燕麦米 可买 1 小袋（500g）混入煮饭（10-20% 比例），改善口感与营养，但**不要全用**

#### 9.9.2 油：买两瓶（主炒菜油 + 凉拌橄榄油）

| 用途 | 推荐 | 容量 | 价格 | 主要场景 |
|------|------|------|------|---------|
| **主炒菜油** | **花生油（压榨一级）** | 5 L | 80-110 元 | 中式爆炒、煎肉煎蛋（耐高温、香）|
| **凉拌/低温油** | **特级初榨橄榄油（EVOO）** | 500 ml | 50-80 元 | 沙拉、淋面包、出锅淋一勺 |
| （可选）调味油 | 芝麻油 / 香油 | 250 ml | 20-30 元 | 出锅点几滴提香 |

**总投入约 130-200 元，可撑 1.5-2 个月。**

**各种油对比（搞懂一次省很多坑）：**

| 油种 | 烟点 | 口感 | 适合 | 增重场景评价 |
|------|------|------|------|-------------|
| **花生油** | 230℃ 高 | 香、黄 | 中式爆炒、煎炸 | ✅ 中式家常首选 |
| 玉米油 / 葵花籽油 | 230℃ 高 | 清淡 | 通用炒菜 | ✅ 便宜可替代花生油 |
| 菜籽油（非转基因）| 200℃ 中 | 略带菜籽香 | 川菜、炒菜 | ✅ 川渝口味推荐 |
| 大豆油 / 调和油 | 200℃ | 一般 | 炒菜 | ⚠️ 调和油成分不透明，能不买不买 |
| **特级初榨橄榄油（EVOO）** | 190℃ 中低 | 果香、微苦 | **凉拌、低温、出锅淋** | ✅ 健康加分项 |
| 普通橄榄油 / 精炼橄榄油 | 240℃ | 寡淡 | 炒菜 | ⚠️ 已精炼营养损失，不如花生油 |
| 牛油果油 | 270℃ 极高 | 清淡 | 高温煎牛排 | ⭐ 贵、健康但非必需 |
| 山茶油（茶油）| 220℃ | 清香 | 通用 | ⭐ 国产 EVOO 替代，贵 |
| 椰子油 | 180℃ | 椰香 | 烘焙 | ⭐ 不必买，除非烘焙 |

**重要避坑：**

1. ❌ **不要买"调和油"**：虽然便宜但成分不透明，长期 omega-6 比例失衡，不利健康。
2. ❌ **不要买大桶橄榄油用来炒菜**：EVOO 烟点低，高温炒菜浪费它的营养又产生有害物质。
3. ❌ **不要买"轻怡 / 减脂"油**：增重正需要油的热量，反向操作。
4. ✅ **看认证**：橄榄油认准 **EVOO** 字样 + 国家原产地标志（如 IGP / DOP）；花生油认准 **GB/T 1534 + "压榨"工艺**（不要"浸出"）。
5. ✅ **小瓶 EVOO 优于大瓶**：开封后接触空气会氧化，500ml 在 2 个月内用完为佳。

#### 9.9.4 「油用法」3 个增重技巧（呼应 9.8 第 1 条）

1. **炒菜默认多加 1 勺**：同样一道菜，1 勺油 → 2 勺油 = +100 kcal，几乎不影响口感和饱腹感——最便宜的热量加法。
2. **米饭/面出锅淋 1 勺 EVOO + 一点酱油 / 蒜蓉**：地中海吃法，+120 kcal、超香、提味又健康。
3. **煎鸡腿 / 煎蛋油给足**：吸了油的鸡腿热量直接翻倍，是瘦子增重最划算的操作。鸡腿用花生油，煎蛋两面金黄淋点 EVOO 出锅。

## 十、调研局限性

1. **个体差异未覆盖**：本菜单基于 60-70 kg 健康男性平均假设，肠胃疾病、糖尿病前期、痛风等人群需医生 / 营养师定制。
2. **过敏 / 不耐受未覆盖**：乳糖不耐、麸质过敏、坚果过敏者需要替换方案（可后续补充）。
3. **热量为估算值**：±10% 误差，最终以体重曲线 + 围度为准。
4. **训练计划未深入**：本报告只覆盖营养，配套抗阻训练计划（推 / 拉 / 腿三分化）未展开。
5. **价格 / 地域差异**：示例食材按一线城市超市/外卖均价估算，三四线城市 / 学生党可参考成本下浮 30%。
6. **健康风险**：菜单含较多红肉与全脂奶制品，**心血管疾病家族史人群**应将红肉换成鱼 / 鸡 / 豆制品，全脂奶换成低脂奶 + 加坚果补脂肪。
