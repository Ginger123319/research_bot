## 一、男士穿搭的本质认知

穿搭不只是审美问题，而是以下几个维度的综合：


| 维度    | 说明                              |
| ----- | ------------------------------- |
| 规则与知识 | 颜色搭配、版型与身材匹配、TPO 场合适配 —— 可习得的技能 |
| 社会信号  | 向外传递身份、职业、圈子的元信息                |
| 自我认知  | 清楚自己是谁、想呈现什么形象                  |
| 审美感知  | 颜色、款式、整体协调感的判断                  |


**核心结论**：审美可以慢慢培养，但先把规则学对，比"等审美提升"更有效率。

## 二、购衣前的准备工作

### 第一步：摸清现状（30分钟，做一次）

在衣柜前把所有衣服拿出来，回答三个问题：

1. **我现在的风格是什么？** 拍几张搭配照，归纳关键词（宽松/合身、深色/浅色、休闲/正式）
2. **哪些衣服从来不穿？为什么？**（不合身？颜色怪？买错场合？）
3. **缺什么？** 是上衣多下装少？还是没有正式场合的衣服？

**产出**：一份"现有风格画像" + 一张"缺口清单"

---

### 第二步：定义"想要的感觉"

"想穿得不一样"太模糊，需要具体化。

**方法**：去小红书/Pinterest 搜索以下风格关键词，保存 10-15 张觉得"对了"的图：

- 日系简约、法式休闲、美式复古、商务休闲（Business Casual）、街头潮流

保存完后，看这些图的**共同点**：

- 颜色主要是什么系（大地色？黑白灰？）
- 版型是宽松还是修身？
- 有没有某类单品反复出现？

**产出**：3 个关键词描述目标风格，比如"简约、偏深色、合身"

---

### 第三步：制定购物清单

基于"缺口清单 + 风格方向"，列出**具体单品**，例如：


| 单品       | 版型/颜色要求  | 预算       |
| -------- | -------- | -------- |
| 白色基础 T 恤 | 合身版型，纯棉  | ¥100-200 |
| 深色直筒裤    | 黑色或深蓝，九分 | ¥200-400 |
| 简单外套     | 米色或卡其色   | ¥300-600 |


**原则**：只买清单上的东西，不因打折或"看起来不错"买计划外的。

## 三、网购时的单品判断框架

拿到一件想买的商品，依次过以下四关：

### 第一关：版型（最重要）

- 翻到评价区，筛选"有图"，找**和自己身材接近**的买家秀
- 如果买家秀集体消失、清一色精修主图，直接划走
- 判断标准：**合不合身**，而不是好不好看

### 第二关：可搭配性

问自己：

> 我现有的衣服，能和这件搭出 3 套吗？

凑不出 3 套 → 大概率闲置 → 不买。

### 第三关：场合明确性

问自己：**我会在什么具体场合穿这件？**

- 能说出具体场合 → 可以考虑
- 回答是"也许哪天会穿" → 不买

### 第四关：价格感知测试

1. **先不看价格**，凭感觉判断自己愿意花多少钱
2. 再看实际价格：
  - 实际价格 ≤ 预估价格 → 可以买
  - 实际价格远超预估 → 冷静，可能是页面氛围带偏了判断

---

## 四、一句话决策口诀

> **合身 + 能搭 3 套 + 知道在哪穿 = 可以买**

三条缺任何一条，等一等，不要冲动下单。

---

## 五、找参考图的注意事项

### 避免被外部信号污染判断

先看图、凭第一感觉打分（1-5 分），**打完分之后**再看点赞数和评论数据。
让"自己的判断"先于"外部信号"发生，而不是反过来。

### 选高质量参考图的标准

1. **优先选街拍/日常场景图**，而不是棚拍精修大片
2. **优先找同类型普通人**的穿搭（"普通男生日常穿搭"、"上班族穿搭"），而不是职业穿搭博主
3. 高赞 + 评论里有人问"这是什么牌子/在哪买"的图 → 自己和他人判断的交集

## 六、避坑提醒

- **不要在睡前刷购物 App**：判断力明显下降，冲动下单概率翻倍
- **不要因为打折买计划外的东西**：便宜买到不穿的，不如贵一点买到常穿的
- **版型不合身不要抱侥幸**：不要指望"回家改改"或"穿几次就习惯了"

## 八、风格定位与术语

**关键词**：简约 normal、兼顾户外功能、**下盘定风格**（裤 + 鞋决定整体气质）、颜色适配黄黑皮（米白、炭灰、藏青、军绿、卡其、黑等）、材质偏向 **硬挺 / 速干 / 不易泄型**（T 恤可用重磅或领口不易荷叶边的款；不必全身「纸板硬」）。

**贴脸色（内搭 T）— 已实证**：通勤要 **提亮** 时，优先 **米白、浅杏、藏青**。**避免高明度、偏冷的 pastel 薄荷绿 / 鼠尾草绿** 作贴身内搭（易显黑，见第十三节）。绿色若要用，优先 **偏浊的军绿 / 橄榄**，且可放在 **裤装或外层**，内搭仍宜用浅色或藏青。**浊橄榄绿贴脸** 在光线不佳时易与黄黑皮 **明度接近显闷**，需自然光下自测；拿不准时同样让内搭换成米杏 / 藏青。

**「壳」**：最外层外套，通常指 **冲锋衣 / 薄硬壳 / 防风防泼水夹克**（与自述「灰色冲锋衣」同角色）。对应 layering 里的 **shell（外壳层）**。

**一件亮点原则**：全身只允许 **一件** 强表达（侧纹裤 / 艳色鞋 / 大图案卫衣等择一），其余用基础色与基础版型托住。

## 十、保留 / 淘汰逻辑与建议清单

**总规则**：与「简约 normal 通勤 + 户外」**冲突大**、**穿着频率极低**、或与另一件 **功能完全重复** 的 —— 优先淘汰或降级（卖 / 送 / 仅家居）。

### 建议保留（核心池 / 角色）

| 角色 | 单品类型 |
|------|-----------|
| 通勤壳 | 灰色冲锋衣；浅灰薄风衣可作替补 |
| 内搭 T | **合身、状态好**的黑 T；日常提亮优先 **米白 / 浅杏 / 藏青** 轮换；**浊色橄榄 / 军绿** 可作备选但需在自然光下自测是否显闷 |
| 衬衫 | 米色衬衫（通勤 / 空调层 / 防晒层替补） |
| 通勤裤 | 卡其、深灰、黑、牛仔中蓝等 **利落直筒** 优先 |
| 鞋 | 白、灰白等 **低饱和运动鞋** 作默认 |
| 户外 / 周末 | 侧纹绿裤、尼龙机能裤、越野向或厚底功能性鞋（按实有款） |
| 凉爽时段 | 炭灰针织：**不必扔**，夏季室外少穿，**空调房 / 露营早晚**可用 |

### 建议淘汰、降级或减至一件

| 动作 | 对象 | 原因（对齐个人目标） |
|------|------|----------------------|
| 淘汰或仅家居 | 褪色软塌、过大的黑 T；通勤路径上的 **拖鞋 + 显眼白袜** | 与「硬挺、normal」不一致 |
| 淘汰或周末专用 | **紫色鞋**（若几乎不穿） | 整合成本高，易偏离 normal |
| **淘汰（已实证）** | **pastel 薄荷绿 / 鼠尾草绿等高明度冷绿 T** | **贴脸显黑**，与内搭提亮目标冲突；新品购置避开该类 |
| 淘汰或仅家居 | **黑色大卡通 / 高饱和印花连帽卫衣** | 观感 **显黑、幼稚**；设计感过强，不入通勤胶囊 |
| 淘汰或谨慎保留 | **其它浅绿 T**（若非 pastel 仍建议单独试穿） | 以 **自然光下气色** 为准；不配则出闲置 |
| 二选一 | 两件 **浅灰拉链卫衣** | 功能重复 → **留 1** |
| 留 0～1 | 两件 **织锦 / 提花袖卫衣** | 设计感权重高 → **至多留 1**，极简可 0 |
| 场景限制（非必扔） | **侧纹绿裤** | **不作 daily 通勤裤**；户外 / 周末 + 纯色上衣 |

## 十一、固定搭配公式（自下而上）

### A. 通勤 normal（默认）

**壳** → **米白 / 浅杏 / 藏青 T（合身、领口挺）** → **卡其 / 深灰 / 黑 / 藏青直筒裤** → **白或灰运动鞋**

- **内搭**：优先 **米白、浅杏、藏青**。**勿用**已证实显黑的 **pastel 薄荷绿** 作贴身内搭。
- **浊橄榄 / 军绿 T**：仅在有自然光确认不显闷时作 rotation，否则仍以浅色内搭为主。
- **裤装**：松紧腰若外露抽绳，通勤时宜 **收起绳头** 或换 **腰头利落的直筒**，更接近「利落 normal」。
- **鞋**：全身浅色系（如浅杏 T + 卡其裤）时，用 **白 / 灰白 / 深棕德训** 压底，避免头脚俱浅发「飘」。

**不要**：侧纹裤、紫鞋、大图案卫衣（与「无设计感通勤」冲突）。

### B. 户外 / 周末

**壳** → **纯色 T（黑 / 白 / 军绿）** → **侧纹绿裤 或 机能尼龙裤（二选一当主角）** → **越野跑鞋或中性球鞋**

**一件亮点**：横纹裤、艳鞋、图案卫衣 **只选一**。

## 十二、胶囊优化方向与购置优先级（下一步计划）

### 缺口与升级方向（自述 + 上文收敛）

1. **米白重磅 T、藏青 T**：提亮、 rotation，夏季室内单穿友好  
2. **速干 / 防晒衬衫**：应对暴晒与温差，可作壳与 T 之间的可脱层  
3. **硬挺直筒裤**：藏青直筒；机能向 **尼龙工装裤**（与户外场景一致）  
4. **下盘分量感**：深棕德训类 **或** 越野跑鞋（按路况二选一或各一）

### 建议下单顺序（预算有限时）

1. 一条 **利落藏青直筒**（或等价硬挺深色休闲直筒）  
2. **米白重磅 T**  
3. **防晒速干衬衫**  
4. **越野跑鞋** 或 **厚底德训 / 功能休闲鞋**  
5. 再补第二条 **机能裤** 或 **藏青 T**

采购时用本文 **第二节购物清单 + 第三节四关** 写死规格（尺码、裤长、克重关键词），避免临时加车。

## 十三、实测与迭代记录（个人上身结论）

> 以下为 **本人试穿 / 镜检 + 自然光感受**，用于修正理论配色；后续有新结论可追加小节。

### 1. 单品结论（淘汰类）

| 单品 | 结论 | 处置 |
|------|------|------|
| **黑色大印花连帽卫衣**（胸前大块卡通、高饱和紫/浅蓝等） | **显黑、幼稚感**；与「简约 normal」不一致 | **淘汰或仅家居**，不纳入通勤胶囊 |
| **pastel 薄荷绿 / 鼠尾草绿纯色 T** | 自然光下自认 **显黑** | **淘汰或极少穿**；**购置时避开高明度冷 pastel 绿贴脸** |

### 2. 搭配试错（结构 vs 气色）

| 组合 | 可取之处 | 调整 |
|------|-----------|------|
| **浅灰壳 + 橄榄绿 T + 卡其裤** | 符合「壳 → T → 裤」层次；色相同属大地系 | 橄榄 **明度与肤色接近** 时易 **显闷**；内搭提亮可换 **米杏 / 米白 / 藏青**；松紧腰 **外露绳** 偏松弛 → 收起或换利落腰头直筒裤 |
| **浅杏 / sand T + 同色系卡其裤**（ tonal ） | **脸部附近提亮**；整体干净、有 intentional 感；符合胶囊叙事 | 鞋宜用 **白 / 灰白 / 深棕德训** 压底；需要层次时可外搭 **灰 / 炭灰壳** |

### 3. 购置时的颜色备忘（收敛自实证）

1. **通勤内搭首选**：米白、浅杏、藏青（重磅或领口挺括者优先）。  
2. **慎选 / 避开**：胸前 **大卡通、高饱和拼色印花**；**高明度冷 pastel 绿** 作贴身 T。  
3. **绿色若保留**：优先 **偏浊军绿 / 橄榄**，并可放在 **裤或外套**；内搭仍以提亮色为主。

### 当前温度窗口（05/19–05/27，北京海淀，2026-05-14 更新）

来源：手机天气 15 日预报截图（海淀区）。

| 维度 | 数值 / 观察 |
|------|--------------|
| 低温区间（早晚） | **15–18°C** |
| 高温区间（白天） | **25–30°C** |
| 昼夜温差 | **8–13°C**（典型 10°C 左右） |
| 偏雨日（≥58%） | 05/20、05/26、05/27（共 3 天） |

**对购置决策的影响（明确证据 → 明确动作）：**
