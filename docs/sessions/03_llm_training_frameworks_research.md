## 执行过程

### 阶段一：需求澄清
- 目标：梳理 2025-2026 年主流大模型训练框架及各自适配的训练场景
- 输出形式：结构化报告 + 对比表 + 选型建议
- 关注点：框架选型依据、训练场景覆盖、生态成熟度

### 阶段二：问题拆解（MECE）
1. 主流框架全景（第一梯队有哪些？）
2. 各框架核心技术特性
3. 框架 × 训练场景映射（预训练 / SFT / RLHF / 多模态 / MoE）
4. 生态与社区活跃度
5. 性能与可扩展性对比

### 阶段三：信息搜集
并行检索 5 个查询：
- 主流框架全景（英文）
- SFT / RLHF 框架对比（英文）
- 中文社区训练框架对比（中文）
- Megatron-LM 生态与多模态信息（英文）
- verl / OpenRLHF RLHF 性能对比（英文）

### 阶段四-五：筛选与整理
- 框架分为三层：基础分布式层、微调层、后训练层
- 关键结论：训练场景决定框架选型，无单一框架最优覆盖所有场景

## 关键结论
1. 预训练首选 Megatron-LM + DeepSpeed 组合
2. SFT 赛道 LLaMA-Factory 与 Unsloth 领跑
3. RLHF 方向 verl（工业）与 OpenRLHF（学术）并立
4. 国产化/昇腾场景 MS-SWIFT 是唯一深度适配方案
5. GRPO 取代 PPO 是 2026 年明显趋势
