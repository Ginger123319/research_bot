### 阶段二：问题拆解（MECE）

1. 长肉的底层原理（热量盈余 / 蛋白质 / 训练）
2. 营养目标计算（按 65 kg 男性 → 3200 kcal 标定）
3. 一周菜单（周一-周日，含训练日特别安排）
4. 上班族执行简化（备餐 / 外卖筛选 / 便利店应急）
5. 加餐与「热量密度放大器」清单
6. 羽毛球日营养时序
7. 误区与自我监控调整

### 阶段三-四：信息搜集与筛选

- 营养目标基于 ISSN（国际运动营养学会）2017 + 2024 蛋白质指南
- 中国居民膳食指南（2022）作为本地化参考
- 食材热量交叉验证：中国食物成分表 + 薄荷健康
- 训练前后营养时序参考 ACSM 2021 指南
- 不做漫无目的搜集，直接基于已知营养学共识 + 实操经验落地

### 阶段五：整理与分析

- 确定**单餐 ≤ 1000 kcal、3 餐 + 2-3 加餐**的结构（瘦子胃容量约束）
- 训练日 +300 kcal（来自训练前后加餐）
- 周末 +菜单升级 + 备餐 → 解决工作日时间紧张
- 形成 7 天具体菜单 + 热量/宏量营养表

### 阶段六：输出

- 报告 → `docs/results/2026-05-06-skinny-weight-gain-weekly-menu.md`
- 会话记录 → 本文件

## 关键结论

1. 长肉公式 = **热量盈余 + 足量蛋白 + 抗阻刺激**，三者缺一不可
2. 目标热量 3200 kcal/日，蛋白 130g（1.7 kcal/g，1.7-2 g/kg 体重）
3. 上班族落地靠**周日 90 分钟备餐**+ 外卖筛选三条标准
4. 羽毛球日重点在**训练后 30 分钟黄金窗口**：蛋白 + 快碳必须到位
5. **「我已经吃很多了」是最大错觉** → 必须用 App 记 3 天饮食对账
6. 高热量密度食物（坚果 / 花生酱 / 全脂奶 / 牛油果）是性价比最高的"加量神器"
