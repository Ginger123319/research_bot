**核心结论**：

- CUDA/Triton kernel 开发是最难被 AI 替代的技能壁垒
- Web 开发只需学到"能指挥 AI、能审查输出"的程度
- Context Engineering（上下文工程）是最重要的元技能转变
- MoE 基础设施和 Agentic 工作负载是值得提前布局的新方向
